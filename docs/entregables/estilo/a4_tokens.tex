{\color{uxnavy}\small Reglas derivadas de la matriz\par}
\begin{enumerate}[leftmargin=*,itemsep=2pt,topsep=4pt]
\item El acento 500 no lleva texto claro encima: con la superficie del producto da 2.68:1 y con blanco puro 2.80:1. Si el ambar 500 lleva texto, el texto es tinta (5.22:1).
\item Todo ambar que informa usa el acento 700 (4.40:1 sobre superficie, por encima del 3:1 de elemento grafico). El acento 500 queda decorativo.
\item El texto de aviso es el acento 900 sobre el acento 100 (7.58:1, AAA). El acento 700 sobre el mismo fondo se queda en 3.96:1 y falla AA.
\item El borde de campo de formulario usa el neutro line-strong (4.55:1). El filete claro line (1.42:1) queda para separadores decorativos.
\item El neutro muted solo rotula texto de 14 px o mas (4.55:1, AA justo): ninguna cifra ni etiqueta menor va en muted.
\end{enumerate}
